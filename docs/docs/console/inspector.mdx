# 流量捕获与请求重放

对 **HTTP / HTTPS** 代理旁路捕获访客流量，可查看请求/响应，并支持**原样重放**或**编辑后重放**。主要应用场景是联调排查、接口复现、改参验证
等场景。

## 怎么用

1. 在 HTTP / HTTPS 代理列表点击 **抓包**
2. 打开抽屉顶部的 **抓包** 开关
3. 产生流量后，在列表中查看记录
4. 选择 **重放** 或 **编辑重放**

:::warning 注意
- **仅支持** HTTP / HTTPS代理协议
- 仅解析 **HTTP/1.x**
- **请求体截断**后不可重放
- `Host`、`Connection`、`Content-Length`、`X-Forwarded-*` 等HTTP头由系统锁定，不可更改
:::
